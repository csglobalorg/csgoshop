# Aeonfree / InfinityFree Hosting Instructions

Aeonfree এবং InfinityFree-এর মতো ফ্রি হোস্টিং সার্ভারে Node.js (Express) চলে না। তাই সেখানে API কাজ করানোর জন্য আমি একটি PHP প্রক্সি ফাইল তৈরি করে দিয়েছি।

### কীভাবে হোস্ট করবেন:

1. প্রথমে আপনার প্রোজেক্টটি বিল্ড করুন (Build button-এ ক্লিক করুন অথবা `npm run build` কমান্ড দিন)।
2. বিল্ড শেষ হলে আপনার প্রোজেক্টের ভেতরে একটি `dist` ফোল্ডার তৈরি হবে।
3. এই `dist` ফোল্ডারের **ভেতরের সব ফাইল** (assets, index.html, api.php ইত্যাদি) আপনার হোস্টিংয়ের `htdocs` ফোল্ডারে আপলোড করুন।
4. আপলোড হয়ে গেলে আপনার ওয়েবসাইটটি ভিজিট করুন।

### কেন এটি দরকার?
সরাসরি Mohasagor API ব্যবহার করলে ব্রাউজার সেটি ব্লক করে দেয় (CORS error)। `api.php` ফাইলটি আপনার সার্ভার থেকে Mohasagor-এর সাথে যোগাযোগ করবে, যা ব্রাউজার ব্লক করতে পারবে না।

**নোট:** আপনার হোস্টিংয়ে যদি CURL এনাবল করা না থাকে, তবে API কাজ করবে না। তবে Aeonfree-তে সাধারণত এটি এনাবল থাকে।
