## 🚀 Live Deployment
This project is configured with an automated CI/CD deployment pipeline via GitHub Actions to Namecheap cPanel hosting (`public_html`).
- **Deployment Guide:** See [DEPLOYMENT.md](DEPLOYMENT.md) for full instructions.

## 🛠️ Run Locally

**Prerequisites:** Node.js (v20+ recommended), npm

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start development server:**
   ```bash
   npm run dev
   ```

3. **Build production bundle:**
   ```bash
   npm run build
   ```
