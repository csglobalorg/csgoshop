## Codebase Patterns
- This project uses a Vite-based frontend with a custom PHP/TypeScript backend.
- Supabase is used for database and authentication.
- Main logic is in `script.js` and `style.css`.
- Hero section uses a split grid layout (992px breakpoint) for premium asset display.
